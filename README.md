#  Indian Premier League (IPL) Analysis Dashboard (2008–2024)

##  Project Overview

This project presents an interactive Power BI dashboard that analyzes the Indian Premier League (IPL) from **2008 to 2024**. The dashboard provides comprehensive insights into team performance, player statistics, batting and bowling records, season winners, toss decisions, and historical IPL trends across all seasons.

##  Objectives

- Analyze IPL performance from 2008 to 2024
- Compare team performance across seasons
- Identify top batsmen and bowlers
- Analyze Orange Cap and Purple Cap winners
- Study toss decisions and their impact on match outcomes
- Build an interactive dashboard for cricket analytics



##  Tools Used

- Power BI
- Microsoft Excel
- Power Query
- DAX



##  Dashboard Features

- Season Filter (2008–2024)
- Overall Tournament KPIs
- Season Winner & Runner-Up
- Orange Cap & Purple Cap Holders
- Top 5 Batsmen
- Top 5 Bowlers
- Team Performance Analysis
- Toss Decision Analysis
- Batting & Bowling Statistics
- Interactive Slicers and Dynamic Visualizations



##  Key Insights

- Compare IPL statistics across all seasons (2008–2024)
- Identify the highest run scorers and wicket takers for each season.
- Analyze team performance and championship history.
- Evaluate the impact of toss decisions on match results.
- Track batting and bowling trends over multiple IPL seasons.
